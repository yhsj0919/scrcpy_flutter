## 后续回归步骤

后续发布回归仍按以下步骤执行：

1. 在设备上进入“开发者选项 → 无线调试 → 使用配对码配对设备”，保持弹窗开启。
2. Demo 点击“验证码配对”，确认自动出现配对服务。
3. 先输入错误码，确认得到 `pairingFailed`。
4. 等待旧码过期后再次提交，确认得到 `pairingFailed`。
5. 使用新码成功配对，确认连接端口自动更新并出现在统一设备列表。

配对地址、设备序列号和配对码不得写入本报告。
