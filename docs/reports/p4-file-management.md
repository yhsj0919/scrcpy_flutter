# P4-06 文件管理基础能力验收

日期：2026-09-02

## 公开 API

`AdbToolkit.files(deviceSerial)` 创建 `AdbFileManager`，提供：

- `listDirectory()`：浏览目录并返回名称、路径、类型、大小和修改时间；
- `push()` / `pull()`：设备与宿主之间传输文件；
- `createDirectory()`：新建单级或递归目录；
- `rename()`：文件或目录重命名；
- `delete()`：删除文件或递归删除目录；
- `exists()`：覆盖前检查远程目标。

所有异步操作均接受 `AdbCancellationToken`。push、rename 默认拒绝覆盖，调用方必须明确传入 `overwrite: true`。删除 `/` 会在执行 ADB 前被拒绝。

## 路径安全

远程路径必须是 Android 绝对路径且不能含 NUL。文件命令通过 `sh -c` 执行时使用两层 POSIX 单引号转义，用户路径不会作为 shell 语法解释。

真机测试覆盖了以下组合：

- 空格；
- 中文；
- 单引号；
- `&` shell 特殊字符。

## Demo

单设备页面右上角提供文件管理入口。页面支持：

- 从 `/sdcard` 开始浏览、进入目录和返回上一级；
- 刷新、新建目录和输入本地路径上传；
- 下载、重命名和删除；
- 进行中的任务显示取消按钮；
- 删除、覆盖及下载目标均展示完整目标并要求确认；
- 错误保留在当前页面，不影响视频会话。

首版不引入平台文件选择器，上传和下载使用本地绝对路径输入，以保持插件边界和跨平台 UI 可替换性。
